## 📖 项目简介

基于 **基频 + 共振峰双重伸缩** 理论，实现男声↔女声↔童声的任意转换。内嵌 SOLA 时域拉伸算法和 LPC 分析合成两种变声方法，支持实时录音、WAV上传、频谱可视化、变速播放和结果导出。

## ✨ 功能

- 🎙️ **录音 / 上传** — 麦克风实时录音或上传 WAV 文件
- 🔮 **4种变声模式** — 男→女 (α=1.6)、女→男 (α=0.6)、男→童 (α=2.2)、女→童 (α=1.5)

## 🔬 技术原理

每个人的声音由**音调**（基频 f₀）和**音色**（共振峰频率）决定。变声 = 基频 × α + 共振峰 × α。

| 声音类型 | 基频 f₀ | 转换方向 | α |
|---------|---------|---------|-----|
| 男声 | 50~170 Hz | → 女声 | 1.6 |
| 女声 | 170~270 Hz | → 男声 | 0.6 |
| 童声 | >270 Hz | ← 男声 | 2.2 |

**方法A**：重采样改变音高 → SOLA 时域拉伸恢复时长  
**方法B**：LPC 分析 → 分离激励源/声道 → 分别搬移 → 合成

## 🛠 技术栈

纯前端实现，单文件 HTML，无需构建工具或后端服务。

- **Web Audio API** — 录音、播放、滤波、离线渲染
- **Canvas 2D** — 60fps 实时频谱可视化
- **SOLA** — Synchronized Overlap-Add 时域拉伸
- **LPC** — 线性预测编码分析合成
